# v0.4.0 Flutter optical port

Reference: v0.3.12 D2/D4. Historical unified page retained. New reference iframe receives Flutter state via same-origin postMessage. F-D2 is an analytic approximation, not a PBR port; F-D4 is a GLSL adaptation, not pixel-identical (nine-tap blur, different normal direction and sampling). Explicit generated scene texture only, not arbitrary Flutter widget backdrop. Shared 23 controls; parameter equivalence and effectiveness not yet validated. Dynamic texture capture is asynchronous and may lag. Web references require CDN Three.js. Native builds use a reference placeholder. Preview columns may scroll independently on small screens. Smoke test replaced with parameter contract test; UI and shader runtime tests remain outstanding. CI build, deployment, visual and performance acceptance pending. M0 open.
