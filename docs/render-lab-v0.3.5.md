# v0.3.5 System Optical Glass

Sources inspected: [glass-material](https://github.com/ConardLi/garden-skills/blob/main/skills/motion-showreel/references/styles/glass-material.md), [liquid-shader](https://github.com/ConardLi/garden-skills/blob/main/skills/motion-showreel/references/styles/liquid-shader.md), [recipes](https://github.com/ConardLi/garden-skills/blob/main/skills/motion-showreel/references/recipes.md), [web design skill](https://github.com/ConardLi/garden-skills/blob/main/skills/web-design-engineer/SKILL.md). Glass recipe recommends Three.js physical transmission and emissive strip lights prefiltered via PMREM; liquid recipe recommends SDF normals and Fresnel; recipes section 12 supplies actual WebGL texture/postprocess example, not a glass shader. No complete iOS UI shader located in inspected sources. C is original 2.5D approximation, not a direct port.

A/B retained; C default. C uses bounded bevel slope, Snell refraction, displacement cap, Schlick Fresnel, procedural strip environment, roughness-dependent light width, approximate linear-light composition, directional lobe and contact shadow. Existing six controls retained; eight new C controls: bevel 12, curvature .65, IOR 1.46 (UI displays minus one), Fresnel .7, roughness .12, reflection .6, angle 315 degrees, shadow .15. Reset returns C. Same static scene for controlled comparison. No actual PMREM, true ray tracing, dynamic scene, theme/color state or multi-shape support yet. Displacement cap is heuristic, not a proof of no foldover. CI and visual/device validation pending. M0 0/6.
