# v0.4.1 Continuous sampling

Based on v0.4.0 user screenshots. Separate FD2 and FD4 shader assets; FD2 uses refract and analytic reflection strip, not full PBR. FD4 retains height-field displacement. Flutter Gaussian preblur textures replace nine-tap ring sampling; FD2 roughness contributes to blur sigma. Reduced shadow/highlight. Capture queue coalesces requests; reference receives last captured scene flags and phase. Ticker rate is not GPU FPS. All 23 controls retained; exact parameter equivalence and runtime effectiveness pending. Historical reference scenes remain independently drawn and are not pixel identical; foreground font adjusted only. No arbitrary widget backdrop yet. Shared GLSL extraction, layout improvements, GPU profiling and full parameter validation remain pending. CI, deployment and visual acceptance not verified. M0 open.
